# Christian film library

A standalone static catalogue of Christian short films. Open index.html in a browser. No build step, API key, account, analytics or video storage is required.

## Current selection
Four Moving Works films with original YouTube links matched to the filmmaker’s own pages. Runtime and language appear only where verified. Editorial summaries and themes are labelled. catalogue.json records source URLs and verification dates.

## Deployment
Live site: https://suhek7.github.io/christian-film-library/

Free GitHub Pages serves the root of main. The repository and website are public with owner approval. This repo is separate from the career site. All four original YouTube players were checked playing in-page on 30 October 2026; availability can change.

## Curation
Weekly curation prioritizes English, then Tamil, then other languages. Add films only after checking the original filmmaker upload, credits, description and availability. Do not infer a film’s language from a translation download. Record missing metadata as unknown. Keep copyrighted films on their original host. Filmmaker submissions require approval; no live submission backend exists.
