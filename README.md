# Christian film library

A standalone static catalogue of Christian short films. Open index.html in a browser. No build step, API key, account, analytics or video storage is required.

## Current selection
Four Moving Works films with original YouTube links matched to the filmmaker’s own pages. Runtime and language appear only where verified. Editorial summaries and themes are labelled. catalogue.json records source URLs and verification dates.

## Deployment
GitHub Pages can serve the root of main after publication is approved. GitHub Free requires a public repository; the site itself is public. No Pages deployment is enabled yet. This repo is separate from the career site.

## Curation
Add films only after checking the original filmmaker upload, credits, description and availability. Do not infer a film’s language from a translation download. Record missing metadata as unknown. Keep copyrighted films on their original host. Filmmaker submissions require approval; no live submission backend exists.

## Rights
Films and thumbnails belong to their respective creators. Inclusion does not imply endorsement or a redistribution licence. No film files are stored here.
